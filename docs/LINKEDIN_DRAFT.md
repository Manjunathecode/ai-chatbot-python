## Title

AI Chatbot Python — Intent-Based Conversational Assistant

## Description

Built a privacy-safe Flask chatbot demonstration that classifies fictional support questions across 18 curated intents using TF-IDF features and a scikit-learn multilayer perceptron. Added confidence-threshold fallback behavior, validated JSON routes, safe browser rendering, original demo responses, and automated tests. The project intentionally avoids generative-AI claims and has no connection to real order, banking, healthcare, payment, or live-agent systems.

GitHub: https://github.com/Manjunathecode/ai-chatbot-python
